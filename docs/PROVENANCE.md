# Provenance

This repository is a public export of the RAS-FR code and result artifacts from the authors'
larger development repository. Manuscript files are intentionally excluded.

The result JSONs retain the original development-repository commit identifiers. Those identifiers
document the exact state used to produce each result but are not Git object identifiers in this
export repository's separate history.

Key original milestones:

- frozen RAS-FR method/results: `8bf12c8`
- DCRA preregistration: `e1c1669` (`dcra-prereg`)
- DCRA generators: `592df45` (`dcra-gen-freeze`)
- DCRA marginal-product truth: `e527d11` (`dcra-estar-freeze`)
- DCRA gate-4 stopping decision: `7b3dc4e` (`dcra-gate4-fail`)

The corresponding preregistrations and decision record are included in this directory. The public
export preserves their contents and identifiers, not the original repository's full unrelated
history.
